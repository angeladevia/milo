# El mundo de Milo

Biblioteca digital con tres libros ilustrados y sus PDF descargables.

El HTML, CSS y JavaScript están en la raíz. Los recursos gráficos, las fuentes y los PDF se incluyen en varias partes para poder cargarlos desde GitHub. Vercel ejecuta `sh compilar.sh` para reconstruir la carpeta `public/`.

Para probar en local, ejecuta `sh compilar.sh` y abre `public/index.html`.
